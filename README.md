## What does "Carpe Diem" mean?

**Carpe diem** is a Latin phrase from the Roman poet **Horace** (written around 23 BCE), meaning **"seize the day."**

The full line reads:

> *"Carpe diem, quam minimum credula postero"*
> — *"Pluck the day, trusting as little as possible in the future."*

It's an invitation to stop waiting for the "right time" and act on what matters *now* — because life is short and uncertain.

### Where did it become famous?

- **Horace** wrote the original line in his collection of poems, the *Odes*.
- It echoed through centuries of poetry — most notably in **Robert Herrick's** 1648 poem *"To the Virgins, to Make Much of Time"* ("Gather ye rosebuds while ye may").
- It entered modern pop culture through the movie **Dead Poets Society (1989)**, where Robin Williams' character Mr. Keating tells his students: *"Carpe Diem. Seize the day, boys. Make your lives extraordinary."*

That movie is where many people — including the creator of this app — first fell in love with the phrase.

## What is this app?

`carpe-diem` is a personal productivity tracker designed around the "seize the day" philosophy. If something matters to you, don't put it off — track it, work on it, and own today.

**Features:**

| Feature | What it does |
|---|---|
| **Tasks** | Create, prioritize, and complete tasks with due dates |
| **Goals** | Set targets and track your progress toward them |
| **Habits** | Build daily habits and watch your streak grow |
| **Notes** | Jot down quick thoughts with a splash of color |
| **Daily Quotes** | A new inspiring quote each day to keep you motivated |

## Getting started

```bash
# Install dependencies
bun install

# Run the dev server
bun run dev
```

The app requires Firebase for authentication and data persistence — see the project config for setup details.
